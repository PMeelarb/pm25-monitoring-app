# PM 2.5 Air Quality Monitoring App 
A mobile application developed during a Hackathon to track PM 2.5 levels for the Nakhon Chai Burin province cluster. 

## Overview
This project focuses on real-time data integration and providing a user-friendly UI for residents to monitor air quality and stay safe from pollution.

## Tech Stack
* **Framework:** React Native, Expo
* **Database / Backend:** Firebase
* **API:** Air4Thai API

## Key Features
* **Real-time Monitoring:** Fetch and visualize PM 2.5 data efficiently.
* **User-friendly UI:** Intuitive and accessible mobile interface for quick updates.
